# Marigold: Repurposing Diffusion-Based Image Generators for Monocular Depth Estimation

We leverage the Marigold：Repurposing Diffusion-Based Image Generators for Monocular Depth Estimation (**CVPR 2024 Oral**) for depth extraction.

Please download the [LCM checkpoint](https://huggingface.co/prs-eth/marigold-lcm-v1-0) and put it in `Depth Extraction/checkpoint/marigold-depth-lcm-v1-0`.

```bash
 python Depth Extraction/depth_extraction.py
 ```
You can find the extracted depth maps in your data root.
